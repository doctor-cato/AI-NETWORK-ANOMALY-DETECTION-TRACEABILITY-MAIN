# Contributing

## Conventions

- Use Python 3.11+; follow PEP 8.
- Add docstrings; keep functions focused.
- Write tests for new logic (`tests/unit/`; `tests/integration/`).
- Update docs when changing behavior.

## Pull request process

- Create a feature branch from `main`.
- Fill PR template (`.github/pull_request_template.md`).
- Ensure CI passes (basic import/test; no dataset required in CI).
- Request review; link to issue if fixed.

## Issue process

- Use templates; include steps to reproduce or design goals.
- Link milestone; assign label.
- Avoid creating blocking issues for M0–M5 core work unless necessary.
