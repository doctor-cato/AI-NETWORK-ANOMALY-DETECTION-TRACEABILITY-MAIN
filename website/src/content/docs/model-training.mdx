## Input boundary

The canonical baseline uses 47 ordered NetFlow features. `Label`, `Attack`, timestamps, IP addresses and L4 ports are excluded from model input. Split membership is assigned before imputation or other learned transformations. Training data and required artifacts are not shipped with this website.

## Reproduction boundary

The repository contains model training entry points and versioned reports, but large `.joblib` artifacts are excluded from Git. An open PR or a report is not proof that a fresh checkout can reproduce the complete artifact chain. Isolation Forest's recorded prerequisite check was blocked; Autoencoder remains an open PR on the audited `main` snapshot.
