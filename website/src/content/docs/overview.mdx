## Purpose

This repository studies network-flow anomaly detection and an evidence-linked traceability architecture. The public website is a static research portal. It does not run a detector or monitor traffic.

The current `main` branch contains the NF-UNSW-NB15-v3 data contract, quality and EDA records, split and preprocessing code, supervised baseline code and reports, and an Isolation Forest component. Behavioral correlation, risk and trace engines, encryption, API and user interface are target system layers or open PR work.

## Evidence levels

**Implemented** means code exists on `main`; **Tested** means behavior has an automated check; **Experimentally validated** requires a real-data run with provenance and metrics. A synthetic fixture or a closed Issue alone does not meet the latter standard.
