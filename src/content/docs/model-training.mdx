## Input boundary

The canonical baseline uses 47 ordered NetFlow features (`nf-unsw-nb15-v3-baseline-47`). `Label`, `Attack`, timestamps, IP addresses and L4 ports are excluded from model input. Split membership is assigned before imputation or other learned transformations. Training data and `.joblib` artifacts are not shipped in Git or on this website.

## Reproduction boundary

Large `.joblib` artifacts are excluded from Git. On a fresh checkout without the Companion Bundle or locally reproduced artifacts, `InferencePipeline` and `/api/v1/models` enforce fail-closed SHA-256 verification and report `BLOCKED / NOT READY` (`HTTP 503`). Note also that `xgb-baseline-1794755807` was trained at commit `7f51390` with `git_dirty=True`, and historical RF vs newer split index parity remains `MEMBERSHIP_EQUIVALENCE: NOT_VERIFIED` in the [split membership audit](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/reports/splits/split_membership_audit_report.md).
