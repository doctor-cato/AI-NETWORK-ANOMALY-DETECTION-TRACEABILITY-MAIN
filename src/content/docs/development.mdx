## Ranh giới thư mục trong repository

Trên `main`, `src/network_anomaly/` chứa mã nghiên cứu, ingestion, inference và FastAPI; `desktop/` chứa ứng dụng desktop Rust Tauri 2 + Svelte 5 (`v0.6.0`); `scripts/` chứa các điểm vào CLI; `data/` chứa manifest và đường dẫn dataset/demo CSV bị Git bỏ qua; `reports/` lưu bằng chứng chất lượng, đánh giá, OpenAPI và kiểm thử E2E; `artifacts/` lưu file nhị phân `.joblib` cục bộ ngoài Git. Cổng thông tin này nằm riêng trên nhánh `site-source` và build thành HTML tĩnh.

## Kiểm tra cơ bản

```powershell
python scripts/check_environment.py
python -m pytest tests/unit/test_basic.py tests/integration/test_pipeline.py -q
python scripts/check_desktop_version.py --check
python -m ruff check .
python -m black --check .
git diff --check
```

Các lệnh trên dùng để kiểm tra mã nguồn, không thay thế cho đánh giá trên dữ liệu thật. CI chạy pytest bằng fixture tổng hợp; các bước phụ thuộc dữ liệu thật hoặc companion `.joblib` sẽ báo `SKIPPED` khi thiếu tệp. Xem thêm [hướng dẫn kiểm thử](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/TESTING.md) và [quy trình phát hành](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/RELEASE_PROCESS.md).
