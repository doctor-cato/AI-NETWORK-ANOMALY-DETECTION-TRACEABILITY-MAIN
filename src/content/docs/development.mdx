## Cấu trúc thư mục repository v2.0

Repository được tổ chức tách biệt giữa mã nguồn runtime, thư viện thu thập Rust, ứng dụng Desktop và bằng chứng thực nghiệm:

- `src/network_anomaly/`: Gói Python cốt lõi gồm `data/` ([v2_schema.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/data/v2_schema.py), [taxonomy.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/data/taxonomy.py)), `preprocessing/` ([pipeline.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/preprocessing/pipeline.py)), `models/` ([registry.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/models/registry.py)), `behavioral/` ([vector.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/behavioral/vector.py)), `crypto/` ([aead.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/crypto/aead.py), [key_manager.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/crypto/key_manager.py), [rotation.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/crypto/rotation.py)), `streaming/` ([live_orchestrator.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/streaming/live_orchestrator.py)) và `api/` ([response_policy.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/api/response_policy.py)).
- `telemetry/netflow-rs/`: Crate Rust độc lập giải mã NetFlow v9 / IPFIX ([telemetry/netflow-rs/src/lib.rs](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/telemetry/netflow-rs/src/lib.rs)).
- `desktop/`: Ứng dụng Desktop Tauri 2 (`2.0.0`) + Svelte 5.
- `data/` & `reports/`: Manifest chia tập, provenance, đặc tả OpenAPI và báo cáo thực nghiệm có kiểm chứng SHA-256.
- `historical/`: Lưu trữ di sản v1 (`UNSW-NB15` / `NF-UNSW-NB15-v3`).

## Quy trình kiểm tra & đồng bộ hợp đồng

Khi sửa đổi mã nguồn Python, giao diện Svelte hoặc crate Rust, chạy đầy đủ các cổng kiểm tra định dạng, kiểu dữ liệu và đồng bộ hợp đồng OpenAPI:

```powershell
python -m ruff check src scripts tests
python -m black --check src scripts tests
python scripts/export_openapi_spec.py --check
python scripts/check_desktop_version.py --check
python -m pytest tests -q -rs --tb=short
npm --prefix desktop run check
npm --prefix desktop run test
cargo test --manifest-path telemetry/netflow-rs/Cargo.toml
git diff --check
```

Để di trú dữ liệu cấu hình cục bộ từ phiên bản v1 sang v2.0, sử dụng [scripts/migrate_v1_to_v2.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/scripts/migrate_v1_to_v2.py) theo hướng dẫn tại [docs/MIGRATION_V1_TO_V2.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/MIGRATION_V1_TO_V2.md).
