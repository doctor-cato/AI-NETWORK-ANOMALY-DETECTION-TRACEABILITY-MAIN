## Ranh giới thư mục trong repository

Trên `main`, `src/network_anomaly/` chứa mã nghiên cứu, ingestion, inference và FastAPI; `desktop/` chứa ứng dụng desktop **Rust / Tauri 2 + Svelte 5 (`v1.0.0`)**; `scripts/` chứa CLI huấn luyện, kiểm chứng và đóng gói sidecar (`scripts/build_backend_sidecar.py`); `data/` chứa manifest và CSV bị Git bỏ qua; `reports/` lưu bằng chứng chất lượng, đánh giá, OpenAPI và ma trận phân phối; `artifacts/` lưu `.joblib` cục bộ ngoài Git. Cổng thông tin này nằm riêng trên nhánh `site-source` và build thành HTML tĩnh.

## Kiểm tra cơ bản

```powershell
python scripts/check_environment.py
python -m pytest tests/unit/test_basic.py tests/integration/test_pipeline.py -q
python scripts/check_desktop_version.py --check
python -m ruff check src scripts tests
python -m black --check src scripts tests
git diff --check
```

Các lệnh trên dùng để kiểm tra mã nguồn, không thay thế cho đánh giá trên dữ liệu thật. CI chạy pytest bằng fixture tổng hợp; các bước phụ thuộc dữ liệu thật hoặc `.joblib` sẽ báo `SKIPPED` khi thiếu tệp. Xem thêm [hướng dẫn kiểm thử](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/TESTING.md) và [quy trình phát hành](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/RELEASE_PROCESS.md).
