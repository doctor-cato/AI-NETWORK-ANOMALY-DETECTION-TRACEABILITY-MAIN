## Mục tiêu

**NetFlow Sentinel v1.0.0** (đồ án AI cuối kỳ) nghiên cứu bài toán phát hiện bất thường trên lưu lượng mạng (NetFlow) gắn với kiến trúc truy vết có bằng chứng trên **NF-UNSW-NB15-v3**. Cổng thông tin công khai này là website tài liệu tĩnh; nó không chạy mô hình phát hiện hay giám sát lưu lượng trực tiếp.

Nhánh `main` hiện tại (`PR #72` đã merge) bao gồm:

- **Ứng dụng Desktop Standalone (`v1.0.0`)**: `Rust / Tauri 2 + Svelte 5 -> Python FastAPI / PyInstaller Sidecar -> SQLite + 4 ML Models`. Khi build từ nguồn theo cấu hình standalone, sidecar đóng gói sẵn 4 `.joblib`, `nf_unsw_nb15_v3_preprocessor.joblib` và lát cắt `demo_flows.csv` — **người dùng cuối không cần cài Python, venv hay Companion Bundle ngoài**.
- **Bằng chứng ML thực nghiệm trên NF-UNSW-NB15-v3**: Random Forest (`MODEL_VALIDATED`, Held-out Test `F1 = 0,999853`), XGBoost (`RESEARCH_ONLY`, `F1 = 0,999984`), Isolation Forest (`RESEARCH_ONLY`, `F1 = 0,5064`) và Autoencoder (`sklearn.neural_network.MLPRegressor (32,16,32)`, `RESEARCH_ONLY`, `F1 = 0,1361`).
- **Ranh giới phát hành & vận hành**: GitHub Release `v1.0.0` hiện là **Source Release**. Bộ cài Windows `.exe` công khai đang ở trạng thái **DEFERRED / BLOCKED** theo Issue #73 và `DISTRIBUTION_AUTHORIZATION.json` (chờ nghiệm thu Clean Windows 10/11 VM E2E và rà soát điều khoản UQ `454104`). Chặn firewall OS thật và AES-256-GCM OS keyring giữ trạng thái `DEFERRED` (chỉ có Dry-Run #27 với `executed = false`).

## Quy ước mức độ bằng chứng

**Implemented** nghĩa là mã nguồn đã có trên `main`; **Tested** nghĩa là hành vi đã có kiểm thử tự động; **Experimentally validated** yêu cầu lượt chạy trên dữ liệu thật có provenance và metric đầy đủ; **Deferred / Blocked** nghĩa là tính năng hoặc phân phối công khai chủ đích chưa kích hoạt hoặc đang chờ điều kiện nghiệm thu (#73).
