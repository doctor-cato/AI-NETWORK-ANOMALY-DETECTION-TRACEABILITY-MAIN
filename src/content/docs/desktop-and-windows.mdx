## Kiến trúc Desktop Tauri 2 + Svelte 5 + FastAPI

Ứng dụng Desktop NetFlow Sentinel v2.0 kết hợp nhân **Rust / Tauri 2 (`2.0.0`)**, giao diện **Svelte 5** và dịch vụ sidecar **Python FastAPI (`0.1.0`) + SQLite**. Giao tiếp giữa giao diện và sidecar chỉ diễn ra qua loopback `127.0.0.1` và bắt buộc xác thực bằng header `X-Sentinel-Session-Token` (so sánh hằng thời gian bằng `hmac.compare_digest`).

```powershell
python scripts/check_desktop_version.py --check
npm --prefix desktop run check
npm --prefix desktop run test
```

## 7 bảng điều khiển (UI Panels) & 3 chế độ vận hành

Giao diện điều hành cung cấp **7 bảng điều khiển chuyên biệt**:

1. **Tổng quan & Trạng thái hệ thống (Dashboard & Readiness)**: Theo dõi trạng thái mô hình, cổng OOD và thông lượng luồng.
2. **Phân tích CSV Ngoại tuyến (Offline CSV Ingestion)**: Nạp tệp CSV theo hợp đồng `canonical-flow-v2-18`, hiển thị kết quả phân loại và tỷ lệ `ABSTAINED_OOD`.
3. **Phát lại Tập dữ liệu (Dataset Replay)**: Điều khiển phát lại luồng từ tập dữ liệu chuẩn với tốc độ cấu hình được (`399.44 flow/s`).
4. **Giám sát Lab Trực tiếp (Live Lab Stream)**: Kết nối bộ thu thập UDP NetFlow v9 / IPFIX Rust (`telemetry/netflow-rs`) và điều phối suy luận theo lô.
5. **Hành vi & Chuỗi thời gian sự cố (Behavioral & Incident Timeline)**: Trực quan hóa vector hành vi 16 chiều trên cửa sổ `10s / 60s / 300s` và chuỗi sự kiện tấn công.
6. **Quản lý khóa & Bằng chứng mật mã (Crypto & Key Lifecycle)**: Quản lý khóa `AES-256-GCM`, bảo vệ khóa gốc bằng **Windows `DPAPI`** (`CryptProtectData` / `CryptUnprotectData`), theo dõi `NonceRegistry` và xoay vòng khóa thích ứng.
7. **Mô phỏng Phản ứng An ninh (Dry-Run Response Policy)**: Đánh giá khuyến nghị phản ứng với khóa an toàn `dry_run = True` (`executed = false`).

## Trạng thái đóng gói NSIS & ủy quyền phân phối

Để đảm bảo tính trung thực của báo cáo kỹ thuật, trạng thái đóng gói và phát hành Windows hiện tại được ghi nhận rõ ràng:

- **Bộ cài NSIS Windows & Kiểm thử E2E trên máy ảo Windows 10/11 sạch (`#148`)**: Đang ở trạng thái **DEFERRED** (hoãn sang giai đoạn đóng gói phân phối sau khi hoàn tất phê duyệt phát hành).
- **Ủy quyền phân phối nhị phân (`#154`)**: Tệp [DISTRIBUTION_AUTHORIZATION.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/governance/DISTRIBUTION_AUTHORIZATION.json) hiện đặt `approved = false`. Toàn bộ 4 mô hình baseline `E0` giữ phân hạng `RESEARCH_ONLY` và chỉ được phép chạy trên kênh `local_offline` phục vụ nghiên cứu.

```powershell
python scripts/verify_companion_artifacts.py --verify-distribution-permission research-only --target-channel local_offline
```
