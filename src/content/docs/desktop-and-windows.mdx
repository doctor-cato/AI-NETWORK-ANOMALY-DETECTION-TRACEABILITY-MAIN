## Kiến trúc đóng gói Standalone (v1.0.0)

Trong kiến trúc **NetFlow Sentinel v1.0.0**, tiến trình Tauri 2 + Svelte 5 khởi chạy **PyInstaller FastAPI Sidecar** (`scripts/build_backend_sidecar.py`, `desktop/src-tauri/tauri.standalone.conf.json`) trên `127.0.0.1` với token phiên 256-bit và SQLite cục bộ.

Khi build bản standalone hoàn chỉnh trên máy Developer/CI có sẵn artifact:

- Bộ cài Windows x64 NSIS nhúng sẵn Sidecar + 4 tệp `.joblib` + `nf_unsw_nb15_v3_preprocessor.joblib` + 200 dòng `demo_flows.csv`.
- **Người dùng cuối** không cần cài Python, không tạo `.venv`, không tải Companion Bundle ngoài và không dùng `git clone`. Dữ liệu phiên lưu tại `%LOCALAPPDATA%\NetFlowSentinel\`.
- **Developer** vẫn có thể chạy hoặc build trực tiếp từ Source Release `v1.0.0` (chế độ `DEVELOPMENT` với `.venv`, `npm run tauri dev` hoặc build sidecar cục bộ).

## Trạng thái phân phối & kiểm chứng phát hành

GitHub Release `v1.0.0` hiện phát hành dưới dạng **Source Release**. Việc phát hành công khai bộ cài Windows `.exe` đang ở trạng thái **BLOCKED / DEFERRED** theo [DISTRIBUTION_AUTHORIZATION.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/reports/governance/DISTRIBUTION_AUTHORIZATION.json) và [Issue #73](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/issues/73) cho đến khi hoàn tất Clean Windows 10/11 VM E2E (`scripts/vm_target_e2e.ps1`) và rà soát điều khoản UQ `454104`.

```powershell
python scripts/check_desktop_version.py --check
python scripts/verify_companion_artifacts.py --verify-distribution-permission research-only --target-channel local_offline
```

Xem chi tiết [hướng dẫn cài đặt Windows](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/WINDOWS_INSTALLATION.md), [quy trình phát hành](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/RELEASE_PROCESS.md) và [ghi chú v1.0.0](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/releases/v1.0.0.md).
