## Kiến trúc đóng gói (v0.6.0)

Bộ cài đặt Windows x64 NSIS (`NetFlow-Sentinel-v0.6.0-windows-x64-setup.exe`) đóng gói giao diện **Svelte 5**, nhân điều phối **Rust / Tauri 2**, mã nguồn **Python backend** (`src/network_anomaly/`, `scripts/run_api.py`, `requirements-runtime.txt`) và các **manifest SHA-256** (`reports/`). Người dùng không cần `git clone` hay khai báo `NETWORK_ANOMALY_REPO_ROOT`. Dữ liệu người dùng (`.venv`, `.joblib`, `data/demo/`, `network_anomaly.db`) được lưu tại `%LOCALAPPDATA%\NetFlowSentinelM6` (chạy được với tài khoản Standard User).

Do `NF-UNSW-NB15-v3` có điều khoản phi thương mại và tệp `.joblib` không lưu trong Git, máy Windows đích cần:

- **Windows 10/11 (x64)** kèm **Microsoft Edge WebView2 Runtime**.
- **Python `>= 3.12` (x64)** phù hợp `requirements-runtime.txt`.
- **Gói Companion Bundle ZIP** (4 mô hình + preprocessor + 200 dòng demo Validation), được kiểm chứng SHA-256 fail-closed với `COMPANION_SHA256SUMS.txt` và tracked manifests.

## Kiểm chứng & attestation phát hành

```powershell
python scripts/check_desktop_version.py --check --expect-version 0.6.0
python scripts/verify_companion_artifacts.py --verify-attestation .\release_e2e_verification.json --expect-installer-sha256 <SHA256> --require-nsis-e2e --require-demo-files
```
