## Dành cho Người dùng cuối (Windows Standalone v1.0.0)

Trong kiến trúc **NetFlow Sentinel v1.0.0**, bản cài đặt Windows NSIS (`NetFlow-Sentinel-v1.0.0-windows-x64-setup.exe`) nhúng sẵn **PyInstaller FastAPI Sidecar**, **4 mô hình ML**, **preprocessor** và **200 dòng demo Validation** ngay lúc đóng gói:

- **Không cần** cài Python hệ thống, tạo `.venv`, hay tải/nạp Companion Bundle riêng.
- Người dùng chuẩn (Standard User) cài đặt và chạy hoàn toàn **offline** (trạng thái lưu tại `%LOCALAPPDATA%\NetFlowSentinel\`).
- **Lưu ý phân phối công khai**: GitHub Release `v1.0.0` hiện phát hành dưới dạng **Source Release**; file cài `.exe` công khai đang **BLOCKED / DEFERRED** theo [Issue #73](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/issues/73) và `DISTRIBUTION_AUTHORIZATION.json` cho tới khi hoàn tất nghiệm thu Clean Windows 10/11 VM và rà soát điều khoản UQ `454104`.

## Dành cho Developer (Build & chạy từ Source Release v1.0.0)

Developer sử dụng Python `>=3.12` (CI kiểm thử `3.11`–`3.14`), Node.js và Rust/Cargo để chạy phát triển hoặc đóng gói lại sidecar/installer cục bộ:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python scripts/check_environment.py
```

Các tài liệu chuẩn về cài đặt gồm [README](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/README.md), [hướng dẫn tái lập](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/REPRODUCIBILITY.md) và [hướng dẫn cài đặt Windows](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/WINDOWS_INSTALLATION.md).

## Tạo dữ liệu demo & khởi chạy API ở chế độ Developer

Khi đã có artifact dữ liệu và mô hình cục bộ, bạn có thể trích xuất 200 dòng demo chỉ từ tập Validation và chạy API trên loopback `127.0.0.1`:

```powershell
$env:PYTHONPATH = "src"
python scripts/prepare_demo_dataset.py --output-dir data/demo --sample-rows 200 --seed 42
python scripts/run_api.py --host 127.0.0.1 --port 8000
```
