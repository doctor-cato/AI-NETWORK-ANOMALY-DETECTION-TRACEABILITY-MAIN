## Yêu cầu hệ thống & thiết lập Python 3.12

NetFlow Sentinel v2.0 yêu cầu **Python `>= 3.11`** cho môi trường nghiên cứu (khuyến nghị **Python `3.12` x64** trên Windows 10/11 để đồng bộ với artifact thực nghiệm), **Node.js 20+** cho giao diện Svelte 5 và **Rust stable toolchain** cho nhân Tauri 2 cùng thư viện thu thập `telemetry/netflow-rs`.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python scripts/check_environment.py
```

Xem hướng dẫn chi tiết tại [Hướng dẫn người dùng v2.0](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/docs/USER_GUIDE_V2.md) và [Hướng dẫn cài đặt Windows](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/docs/WINDOWS_INSTALLATION.md).

## Chế độ fail-closed `"deployment"` và `NETFLOW_OOD_GATE_SHA256`

Ở cấu hình mặc định `runtime_mode="deployment"`, pipeline suy luận hoạt động theo cơ chế **fail-closed**: hệ thống bắt buộc kiểm chứng mã băm SHA-256 của cổng từ chối OOD thông qua biến môi trường `NETFLOW_OOD_GATE_SHA256` trước khi cho phép nạp mô hình. Khi phát triển cục bộ hoặc kiểm thử với artifact nghiên cứu `RESEARCH_ONLY`, bạn có thể cung cấp mã băm SHA-256 đã xác minh và kiểm tra toàn vẹn gói companion:

```powershell
$env:PYTHONPATH = "src"
python scripts/verify_companion_artifacts.py --verify-distribution-permission research-only --target-channel local_offline
```

## Kiểm chứng demo 2 lượt trên trạng thái sạch (2x Clean-State Verification)

Để chứng minh khả năng cài đặt và vận hành lặp lại 100% mà không phụ thuộc trạng thái lưu sẵn, script [scripts/verify_clean_state_demo.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/scripts/verify_clean_state_demo.py) khởi tạo thư mục tạm cô lập hoàn toàn, chạy trọn vòng đời nạp dữ liệu, suy luận, phân tích hành vi, mã hóa bằng chứng và đối chiếu kết quả qua 2 lượt chạy độc lập:

```powershell
python scripts/verify_clean_state_demo.py
```

Kết quả đã kiểm chứng tại [clean_state_demo_verification.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/demo/clean_state_demo_verification.json) xác nhận `repeatable_100pct = true` giữa hai lượt chạy độc lập.
