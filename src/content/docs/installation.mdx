## Môi trường Python nghiên cứu

Gói nguồn Python khai báo yêu cầu tối thiểu `>=3.11` trong `pyproject.toml` (CI chạy trên Python 3.11 và 3.12). Riêng runtime của ứng dụng Desktop Windows `v0.6.0` (`requirements-runtime.txt`) yêu cầu **Python `>=3.12` (x64)** để tương thích các tệp `.joblib` đã huấn luyện (`numpy 2.5.x`, `pandas 3.0–3.1`, `scikit-learn 1.9.x`, `xgboost 3.4.x`, `joblib 1.6.x`).

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python scripts/check_environment.py
```

Các tài liệu chuẩn về cài đặt gồm [README](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/README.md), [hướng dẫn tái lập](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/REPRODUCIBILITY.md) và [hướng dẫn cài đặt Windows](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/WINDOWS_INSTALLATION.md).

## Tạo dữ liệu demo & khởi chạy FastAPI cục bộ

Khi đã có sẵn artifact dữ liệu và mô hình, bạn có thể trích xuất 200 dòng demo chỉ từ tập Validation và chạy API trên loopback `127.0.0.1`:

```powershell
$env:PYTHONPATH = "src"
python scripts/prepare_demo_dataset.py --output-dir data/demo --sample-rows 200 --seed 42
python scripts/run_api.py --host 127.0.0.1 --port 8000
```

## Xem trước cổng thông tin tĩnh

```powershell
npm ci
npm run dev
```
