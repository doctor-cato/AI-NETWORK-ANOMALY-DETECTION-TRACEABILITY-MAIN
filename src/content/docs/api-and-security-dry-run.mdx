## Hợp đồng REST trên loopback

`scripts/run_api.py` chỉ lắng nghe trên loopback (`127.0.0.1`, từ chối `0.0.0.0`), dùng SQLite đơn chủ ghi và cung cấp 18 endpoint (`/health`, `/api/v1/models`, `/api/v1/csv/*`, `/api/v1/incidents/*`, `/api/v1/timeline`, `/api/v1/keys`, `/api/v1/rotation*`, `/api/v1/security/simulate-response`, `/api/v1/security/simulations*`). Khi khởi chạy từ Tauri, mọi lời gọi `/api/v1/*` bắt buộc truyền header `X-Sentinel-Session-Token` (token 256-bit `NETWORK_ANOMALY_API_TOKEN`).

## Truy vết tất định, rủi ro & Dry-Run (#27)

- **Thống kê hành vi (#28)** và **timeline tất định (#24)** tổng hợp từ metadata NetFlow (`FLOW_START_MILLISECONDS`, IP, port, protocol) kèm tuyên bố không quy kết danh tính cá nhân và nhãn `[OOD ABSTAINED]`.
- **Chấm điểm ưu tiên rủi ro (#32)** ánh xạ xác suất hoặc khoảng cách ngưỡng sang `[0, 100]` và trả về `ABSTAINED_OOD` cho dòng OOD.
- **Mô phỏng phản ứng an ninh thích ứng (#27)** tạo khuyến nghị tất định (`NO_ACTION`, `MONITOR`, `INVESTIGATE`, `ISOLATE_RECOMMENDED`) và quyết định xoay khóa mô phỏng với **`executed = false`**. Chỉ phân tích được server xác minh đạt `MODEL_VALIDATED` + `PREDICTION_AVAILABLE` mới được nâng cấp `ISOLATE_RECOMMENDED`, và cấm containment đối với dòng `ABSTAINED_OOD`. Tự động hóa firewall hệ điều hành và AES-256-GCM OS keyring vẫn **DEFERRED**.
