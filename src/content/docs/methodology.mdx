## Split before fit

The v3 dataset is a single CSV. The repository's chronological, group-aware split places 5-minute purge gaps between Train (`1,655,797`), Validation (`345,371`) and Test (`345,953`). Imputation and other learned statistics are fitted only on Train; model selection and score thresholds belong exclusively to Validation; Test is evaluated once after freezing.

## Supervised vs unsupervised protocols

Binary classification uses `Label=1` for Attack and label order `[0, 1]`. Supervised baselines emit `attack_probability` in `[0, 1]`. Unsupervised detectors (Isolation Forest, Autoencoder) fit on benign-only Train (`1,590,608` rows), isolate `{Backdoor, Worms}` as unknown holdout families, calibrate thresholds on Validation (`max-F1-on-known-attacks` for Isolation Forest; `fpr_constrained` at `FPR <= 0.05` for Autoencoder), and emit `raw_anomaly_score` with `attack_probability = null`.
