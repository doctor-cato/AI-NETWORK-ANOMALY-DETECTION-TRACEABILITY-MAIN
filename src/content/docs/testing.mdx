## Kiểm thử hành vi tự động

```powershell
python scripts/check_environment.py
python -m pytest tests/unit/test_basic.py tests/integration/test_pipeline.py -q
python scripts/export_openapi_spec.py --check
python scripts/check_desktop_version.py --check
```

Workflow CI chạy Python trên Windows và Ubuntu, kiểm tra Svelte (`npm --prefix desktop run check` và `test`), và Rust (`cargo clippy`, `cargo test`). CI không tự tải dataset có điều khoản hạn chế; các test tổng hợp kiểm chứng logic phần mềm chứ không thay thế hiệu năng thật trên NF-UNSW-NB15-v3.

## Xác minh Standalone & Clean VM E2E

Một bản phát hành bộ cài Windows công khai (`Issue #73`) yêu cầu chạy `verify_companion_artifacts.py --verify-e2e --standalone-embedded` trên máy build và `scripts/vm_target_e2e.ps1` trên Clean Windows 10/11 VM. Một bước dữ liệu báo `SKIPPED`, dù mã thoát bằng 0, vẫn phải ghi nhận là `SKIPPED` trong mọi báo cáo.
