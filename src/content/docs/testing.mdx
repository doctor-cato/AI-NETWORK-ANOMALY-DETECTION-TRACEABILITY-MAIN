## Kiểm thử hành vi tự động

```powershell
python scripts/check_environment.py
python -m pytest tests -q
python scripts/export_openapi_spec.py --check
python scripts/check_desktop_version.py --check
```

Workflow CI Python chạy trên Windows và Ubuntu (Python 3.11 và 3.12), kiểm tra import, cú pháp, unit, API và integration tests. CI không tự tải dataset có điều khoản hạn chế; các test tổng hợp kiểm chứng logic phần mềm chứ không thay thế hiệu năng thật trên NF-UNSW-NB15-v3.

## Xác minh Companion E2E & nghiên cứu

Một bản phát hành Stable bắt buộc chạy `python scripts/verify_companion_artifacts.py --verify-e2e` trên môi trường có đủ 4 tệp `.joblib` và bộ `data/demo/`. Một bước dữ liệu báo `SKIPPED`, dù mã thoát bằng 0, vẫn phải ghi nhận là `SKIPPED` trong mọi báo cáo.
