## Tầng dữ liệu, cổng OOD và mô hình ML

Pipeline hiện hành kiểm tra tệp CSV NetFlow theo hợp đồng 47 đặc trưng, xác minh nguồn dữ liệu (`source:nf-v3-canonical` so với `source:nf-v3-unverified`), lọc dòng ngoài phân phối (`ABSTAINED_OOD`) trước khi đưa vào mô hình, biến đổi bằng `TrainOnlyPreprocessor` và chạy suy luận kiểm chứng SHA-256 trên Random Forest, XGBoost, Isolation Forest và Autoencoder. Xem [kiến trúc chuyển đổi v3](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/NF_UNSW_NB15_V3_MIGRATION_ARCHITECTURE.md) và [thiết kế tiếp nhận đa nguồn](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/MULTI_SOURCE_INGESTION.md).

## Ứng dụng Desktop MVP & các phần hoãn

[Kiến trúc hệ thống hợp nhất](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/ARCHITECTURE.md) kết nối giao diện desktop Windows **Rust / Tauri 2 + Svelte 5 (`v1.0.0`)** với **Python FastAPI / PyInstaller Sidecar (`127.0.0.1`) + SQLite** (`18` endpoint trong [hợp đồng API](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/reports/api/API_CONTRACT.md)) nhúng 4 mô hình lúc build (không cần venv trên máy người dùng cuối). Thống kê NetFlow (`#28`), chấm điểm ưu tiên (`#32`), timeline (`#24`) và Dry-Run (`#27`, `executed=false`) chạy cục bộ; tự động hóa firewall OS, AES-256-GCM OS keyring và phân phối `.exe` công khai (`#73`) vẫn ở trạng thái hoãn (`DEFERRED / BLOCKED`).
