## Python 3.12+ environment setup

NetFlow Sentinel v2.0 requires **Python `>= 3.12` (x64)** on Windows 10/11 or Linux to match the v2 runtime dependencies and SHA-256-verified `.joblib` artifacts (`numpy`, `pandas`, `scikit-learn`, `xgboost`, `cryptography`, `fastapi`).

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python scripts/check_environment.py
```

Consult the [README](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/README.md), [v2.0 user guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/docs/USER_GUIDE_V2.md), [Windows installation guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/docs/WINDOWS_INSTALLATION.md) and [v1-to-v2 migration guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/docs/MIGRATION_V1_TO_V2.md) before configuring local artifacts.

## Fail-closed deployment mode & 2x clean-state verification

In v2.0, `InferencePipeline` defaults to `runtime_mode="deployment"`, which fails closed unless a trusted **`NETFLOW_OOD_GATE_SHA256`** digest is provided and matches `artifacts/models/v2/e0/ood_rejection_gate.joblib`. To verify end-to-end clean-state repeatability across two isolated execution passes (`repeatable_100pct = true`) and check local companion artifacts (`local_offline` channel):

```powershell
python scripts/verify_companion_artifacts.py --verify-distribution-permission research-only --target-channel local_offline
python scripts/verify_clean_state_demo.py
```

See the [clean-state verification script](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/scripts/verify_clean_state_demo.py), [clean-state demo report](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/demo/clean_state_demo_verification.json) and [companion verifier](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/scripts/verify_companion_artifacts.py).

## Migrating a legacy v1 workspace & starting the sidecar

If upgrading from a v0.6.0 / v1 checkout, run the automated migration check and start the loopback FastAPI sidecar:

```powershell
python scripts/migrate_v1_to_v2.py --dry-run
$env:PYTHONPATH = "src"
python scripts/run_api.py --host 127.0.0.1 --port 8000
```

See [scripts/migrate_v1_to_v2.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/scripts/migrate_v1_to_v2.py) for legacy artifact archiving rules.
