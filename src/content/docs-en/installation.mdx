## For End Users (Windows Standalone v1.0.0)

In **NetFlow Sentinel v1.0.0**, the Windows NSIS standalone installer (`NetFlow-Sentinel-v1.0.0-windows-x64-setup.exe`) embeds the **PyInstaller FastAPI Sidecar**, **4 ML `.joblib` models**, **train-only preprocessor**, and **200-row Validation demo slice** at build time:

- **No** system Python, `.venv`, or external Companion Bundle ZIP is required on end-user machines.
- Runs **offline** under a Standard Windows user (`%LOCALAPPDATA%\NetFlowSentinel\`).
- **Distribution status notice**: GitHub Release `v1.0.0` currently ships as a **Source Release**. Public `.exe` binary downloads remain **BLOCKED / DEFERRED** under [Issue #73](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/issues/73) and `DISTRIBUTION_AUTHORIZATION.json` until Clean Windows 10/11 VM E2E and UQ `454104` license review conclude.

## For Developers (Source Release v1.0.0)

Developers use Python `>=3.12` (CI verifies `3.11`–`3.14`), Node.js, and Rust/Cargo to develop, run FastAPI directly, or build the standalone sidecar/installer locally:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python scripts/check_environment.py
```

Canonical references: [README](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/README.md), [reproducibility guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/REPRODUCIBILITY.md) and [Windows installation guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/WINDOWS_INSTALLATION.md).

## Developer demo & FastAPI startup

Once dataset and model artifacts exist locally, generate the 200-row Validation-only demo CSV and launch FastAPI on loopback `127.0.0.1`:

```powershell
$env:PYTHONPATH = "src"
python scripts/prepare_demo_dataset.py --output-dir data/demo --sample-rows 200 --seed 42
python scripts/run_api.py --host 127.0.0.1 --port 8000
```
