## Purpose

This repository studies network-flow anomaly detection and an evidence-linked traceability architecture. The public website is a static research portal. It does not run a detector or monitor traffic.

The current `main` branch contains the NF-UNSW-NB15-v3 data contract, quality and EDA records, chronological split and train-only preprocessing code, **real-data Validation and Held-out Test evidence for all four models** (Random Forest, XGBoost, Isolation Forest and Autoencoder), a cross-dataset audit on `NF-CSE-CIC-IDS2018-v3`, an OOD abstention and provenance gate, a localhost FastAPI + SQLite service, and the **Rust / Tauri 2 + Svelte 5 desktop prototype (`v0.6.0`)**. Live OS firewall actions and production AES-256-GCM OS keyring storage remain deferred.

## Evidence levels

**Implemented** means code exists on `main`; **Tested** means behavior has an automated check; **Experimentally validated** requires a real-data run with provenance and metrics; **Deferred** means an operational capability (such as live firewall automation or OS keyring rotation) is intentionally excluded from runtime execution. A synthetic fixture or a closed Issue alone does not establish experimental validation.
