## Purpose

**NetFlow Sentinel v1.0.0** (Final-Year AI Project) investigates NetFlow network-anomaly detection paired with an evidence-linked traceability architecture on **NF-UNSW-NB15-v3**. This public website is a static documentation portal; it does not run models or monitor live traffic.

The `main` branch (`PR #72` merged) delivers:

- **Standalone Desktop Application (`v1.0.0`)**: `Rust / Tauri 2 + Svelte 5 -> Python FastAPI / PyInstaller Sidecar -> SQLite + 4 ML Models`. When built from source in standalone mode, the sidecar embeds all four `.joblib` models, `nf_unsw_nb15_v3_preprocessor.joblib`, and the 200-row `demo_flows.csv` slice — **end users require zero external Python, venv or Companion Bundle**.
- **Real-Data ML Evidence on NF-UNSW-NB15-v3**: Random Forest (`MODEL_VALIDATED`, Held-out Test `F1 = 0.999853`), XGBoost (`RESEARCH_ONLY`, `F1 = 0.999984`), Isolation Forest (`RESEARCH_ONLY`, `F1 = 0.5064`), and Autoencoder (`sklearn.neural_network.MLPRegressor (32,16,32)`, `RESEARCH_ONLY`, `F1 = 0.1361`).
- **Release & Operational Boundaries**: GitHub Release `v1.0.0` is currently published as a **Source Release**. Public Windows `.exe` binary distribution stays **DEFERRED / BLOCKED** under Issue #73 and `DISTRIBUTION_AUTHORIZATION.json` (awaiting Clean Windows 10/11 VM E2E sign-off and UQ `454104` license review). Live OS firewall actions and AES-256-GCM OS keyring rotation remain `DEFERRED` (Dry-Run #27 only, `executed = false`).

## Evidence levels

**Implemented** means code exists on `main`; **Tested** means automated tests pass; **Experimentally validated** requires a provenance-bound real-data evaluation; **Deferred / Blocked** marks operational or distribution capabilities intentionally disabled or gated on sign-off (#73).
