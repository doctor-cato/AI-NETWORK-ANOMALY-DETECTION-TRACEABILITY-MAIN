## Loopback FastAPI contract (`33` paths / `35` operations)

The v2.0 sidecar API (`version 0.1.0`) binds strictly to `127.0.0.1` and exposes **`33` REST paths (`35` HTTP operations)** documented in [reports/api/API_CONTRACT.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/api/API_CONTRACT.md) and [reports/api/openapi.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/api/openapi.json). Every non-health endpoint enforces **`X-Sentinel-Session-Token`** verification via constant-time `hmac.compare_digest` (returning `HTTP 401/403` on missing or invalid tokens).

Endpoint groups cover:

- System readiness, model registry (`RESEARCH_ONLY` badges) and OOD gate status (`/health`, `/api/v1/models`, `/api/v1/system/*`).
- Offline CSV ingestion, dataset replay and live UDP NetFlow v9/IPFIX streaming control (`/api/v1/csv/*`, `/api/v1/stream/*`).
- Incident queue, 16-D behavioral session timelines and composite 0–100 risk breakdown (`/api/v1/incidents/*`, `/api/v1/timeline`, `/api/v1/behavioral/*`).
- Cryptographic telemetry storage, Windows `DPAPI` keystore status and adaptive key rotation (`/api/v1/keys*`, `/api/v1/rotation*`, `/api/v1/crypto/*`).
- Deterministic dry-run containment policy evaluation (`/api/v1/security/simulate-response`, `/api/v1/security/simulations*`).

## `AES-256-GCM` + `NonceRegistry` + Windows `DPAPI` + Adaptive Key Rotation

Implemented in [src/network_anomaly/crypto/aead.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/src/network_anomaly/crypto/aead.py), [src/network_anomaly/crypto/key_manager.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/src/network_anomaly/crypto/key_manager.py) and [src/network_anomaly/crypto/rotation.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/src/network_anomaly/crypto/rotation.py):

- **Authenticated encryption & nonce safety**: Flow records are encrypted with `AES-256-GCM` (`96-bit` nonce, associated provenance metadata) guarded by `NonceRegistry` to prevent nonce reuse. On Windows hosts, master keys are wrapped with **Windows `DPAPI`**.
- **RQ5 Adaptive Key Rotation**: Risk-triggered key rotation in [rq5_rotation_experiment.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/crypto/rq5_rotation_experiment.json) reduces key exposure window by **`-87.5%`** and compromise blast radius by **`-85.0%`** compared to static 24-hour schedules.
- **RQ6 Cryptographic Throughput**: In [crypto_benchmark_report.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/benchmarks/crypto_benchmark_report.json), `AES-256-GCM` reaches **`72,177.2 ops/s`** (`17.62 MiB/s`) at `256B` payloads with mean latency `11.55 us` and **P95 latency `13.3 us`**.

## `ResponsePolicy` locked at `dry_run = True` (`executed = false`)

In [src/network_anomaly/api/response_policy.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/src/network_anomaly/api/response_policy.py), `ResponsePolicy` is hard-locked at **`dry_run = True`** (`executed = false`). It emits deterministic advisory recommendations (`NO_ACTION`, `MONITOR`, `INVESTIGATE`, `ISOLATE_RECOMMENDED`) without modifying OS firewall rules or disrupting host network interfaces.
