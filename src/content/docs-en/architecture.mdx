## Data, OOD gate and model layer

The implemented pipeline validates NetFlow CSV files against the 47-feature contract, verifies source provenance (`source:nf-v3-canonical` vs `source:nf-v3-unverified`), filters out-of-distribution (`ABSTAINED_OOD`) flows before ML inference, transforms features with `TrainOnlyPreprocessor` and executes SHA-256-verified inference across Random Forest, XGBoost, Isolation Forest and Autoencoder. See the [migration architecture](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/NF_UNSW_NB15_V3_MIGRATION_ARCHITECTURE.md) and [multi-source ingestion design](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/MULTI_SOURCE_INGESTION.md).

## Desktop MVP & deferred capabilities

The [consolidated system architecture](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/docs/ARCHITECTURE.md) replaces the earlier Streamlit plan with a **Rust / Tauri 2 + Svelte 5** Windows desktop app (`v0.6.0`) backed by a local-only **Python FastAPI (`127.0.0.1`) + SQLite** service (`18` endpoints in [API contract](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/d1d16e1cafa79a8f515efa4b0a0e60a50a3b5e48/reports/api/API_CONTRACT.md)). NetFlow behavioral stats (`#28`), deterministic priority (`#32`), deterministic timeline (`#24`) and dry-run response (`#27`, `executed=false`) are implemented within NetFlow boundaries; live OS firewall commands and AES-256-GCM keyring rotation remain deferred.
