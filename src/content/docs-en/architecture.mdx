## Data, OOD gate and model layer

The implemented pipeline validates NetFlow CSV files against the 47-feature contract, verifies source provenance (`source:nf-v3-canonical` vs `source:nf-v3-unverified`), filters out-of-distribution (`ABSTAINED_OOD`) flows before ML inference, transforms features with `TrainOnlyPreprocessor` and executes SHA-256-verified inference across Random Forest, XGBoost, Isolation Forest and Autoencoder. See the [migration architecture](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/NF_UNSW_NB15_V3_MIGRATION_ARCHITECTURE.md) and [multi-source ingestion design](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/MULTI_SOURCE_INGESTION.md).
