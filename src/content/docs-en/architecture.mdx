## Hybrid Desktop-Sidecar 7-module architecture

NetFlow Sentinel v2.0 implements a local-only hybrid architecture described in [docs/ARCHITECTURE.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/ARCHITECTURE.md). It couples a native **Tauri 2 + Svelte 5** desktop workstation to a loopback **FastAPI + SQLite** sidecar and an optional pure-Rust **NetFlow v9 / IPFIX** telemetry collector:

1. **Ingestion & Collector Layer**: CSV ingestion adapters (`AIT-NDS-v2`, `CTU-SME-11`, `UWF-ZeekData24`) and the pure-Rust [telemetry/netflow-rs](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/telemetry/netflow-rs/src/lib.rs) collector ([docs/NETFLOW_COLLECTOR.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/NETFLOW_COLLECTOR.md)).
2. **Schema & Anti-Imputation Validator**: Enforces `canonical-flow-v2-18` ([src/network_anomaly/data/v2_schema.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/data/v2_schema.py)) and rejects missing base columns as `FEATURE_INCOMPATIBLE`.
3. **Train-Only Preprocessor**: `TrainOnlyPreprocessor` (`asinh_robust`, `MIN_BOUNDED_SCALE_FLOOR = 0.25`) in [src/network_anomaly/preprocessing/pipeline.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/preprocessing/pipeline.py).
4. **Fail-Closed OOD Gate & ML Ensemble**: In default `runtime_mode="deployment"`, requires a verified `NETFLOW_OOD_GATE_SHA256` digest, runs `OODValidator` + `OODRejectionGate`, abstains out-of-distribution flows (`ABSTAINED_OOD`), and scores in-distribution flows across 4 `E0` baselines (`RESEARCH_ONLY`) and Stage-2 6-class taxonomy ([src/network_anomaly/models/registry.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/models/registry.py)).
5. **16-D Behavioral Correlation Engine**: Extracts 5-minute tumbling window behavioral vectors per `src_ip` ([src/network_anomaly/behavioral/vector.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/behavioral/vector.py), [docs/BEHAVIORAL_ENGINE.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/BEHAVIORAL_ENGINE.md)).
6. **Composite Risk & Dry-Run Policy Engine**: Computes deterministic 0–100 risk scores and dry-run response policies (`dry_run = True`, `executed = false` in [src/network_anomaly/api/response_policy.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/api/response_policy.py)).
7. **Cryptographic Storage & Adaptive Rotation**: Protects sensitive flow telemetry using `AES-256-GCM`, `NonceRegistry`, Windows `DPAPI` and risk-adaptive key rotation ([src/network_anomaly/crypto/aead.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/crypto/aead.py), [src/network_anomaly/crypto/rotation.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/crypto/rotation.py)).

## Five canonical data contracts

- **`CanonicalSecurityEvent`**: Traceable flow envelope carrying timestamps, 5-tuple metadata, dataset/scenario provenance and audit identifiers.
- **`MLFeatureVector` (`canonical-flow-v2-18`)**: Strictly ordered 18-feature vector (6 base bidirectional L4 flow metrics + 12 deterministic ratios, rates, log transforms and port indicators) with zero IP/port/TTL shortcut leakage.
- **`BehavioralVector` (16-D)**: Session-level aggregation across 5-minute windows (`flow_count`, unique destinations/ports, fan-out ratios, inter-arrival statistics and byte asymmetries).
- **`RiskScoreResult`**: Composite `[0, 100]` risk breakdown (`ml_component`, `ood_state`, `behavioral_boost`, `recommended_action`, `dry_run = True`).
- **`KeyLifecycleMetadata`**: Cryptographic key version, creation/rotation timestamps, nonce counter, DPAPI wrapping state and rotation trigger provenance.
