## Canonical 18-feature contract (`canonical-flow-v2-18`)

Defined in [src/network_anomaly/data/v2_schema.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/data/v2_schema.py) and documented in [docs/MULTI_SOURCE_INGESTION.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/MULTI_SOURCE_INGESTION.md) and [docs/FEATURE_COMPATIBILITY_MATRIX.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/FEATURE_COMPATIBILITY_MATRIX.md), the **`canonical-flow-v2-18`** schema consists of **6 base bidirectional L4 flow fields** (`duration_ms`, `in_pkts`, `out_pkts`, `in_bytes`, `out_bytes`, `proto`) and **12 deterministic derived features** (`total_pkts`, `total_bytes`, `bytes_per_pkt`, `pkt_rate`, `byte_rate`, `in_out_bytes_ratio`, `in_out_pkts_ratio`, `mean_in_pkt_size`, `mean_out_pkt_size`, `log1p_duration_ms`, `log1p_total_bytes`, `is_well_known_dst_port`).

- **Strict anti-imputation (`FEATURE_INCOMPATIBLE`)**: Missing base columns or unparseable flow fields are never silently zero-filled or median-imputed across sources; non-conforming inputs are rejected fail-closed as **`FEATURE_INCOMPATIBLE`**.
- **Unified 6-class taxonomy**: Mapped in [src/network_anomaly/data/taxonomy.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/data/taxonomy.py) across `Benign`, `Recon_Scanning`, `Discovery_Enum`, `Web_Exploit`, `Credential_Attack` and `Exfiltration_C2`.

## Phase 0 data integrity fixes (`DATA-A01..A03`) & verified counts

Before training any v2 model, Phase 0 resolved three critical raw-data defects:

- **`DATA-A01`**: Fixed Zeek missing token (`-`, `(empty)`) and millisecond duration conversion across multi-source flow logs.
- **`DATA-A02`**: Quarantined **`942` unmapped flows** in `AIT-NDS-v2` so they are never mislabeled as Benign or Attack, leaving **`3,464,400`** verified labeled rows (`3,401,563` Benign + `62,837` Attack).
- **`DATA-A03`**: Standardized bidirectional packet/byte counters and protocol codes across **`CTU-SME-11`** (`251,219` rows) and evaluation-only **`UWF-ZeekData24`** (`95,871` rows) in [reports/datasets/v2_multi_source_profile.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/reports/datasets/v2_multi_source_profile.json).

## AIT NDS-LDS linkage & timestamp alignment audit (`#85`)

```powershell
python scripts/verify_ait_timestamp_alignment.py
```

The audit in [docs/dataset/AIT_LINKAGE_FEASIBILITY.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/dataset/AIT_LINKAGE_FEASIBILITY.md), [scripts/verify_ait_timestamp_alignment.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/scripts/verify_ait_timestamp_alignment.py) and [reports/datasets/ait_timestamp_alignment_report.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/reports/datasets/ait_timestamp_alignment_report.json) proves that **`DIRECT_UID_LINK = FALSE`** between `AIT-NDS-v2` network flows and `AIT-LDS-v2.1` host logs (`72.87–87.91%` multi-flow ambiguity within timestamp windows). Consequently, v2 uses `5-minute` behavioral session aggregation (`src_ip`) rather than claiming 1-to-1 flow-to-host-log UID joins.
