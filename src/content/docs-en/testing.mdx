## Automated behavior checks

```powershell
python scripts/check_environment.py
python -m pytest tests/unit/test_basic.py tests/integration/test_pipeline.py -q
python scripts/export_openapi_spec.py --check
python scripts/check_desktop_version.py --check
```

CI checks Python across Windows and Ubuntu, Svelte (`npm --prefix desktop run check` & `test`), and Rust (`cargo clippy`, `cargo test`). Restricted dataset files are never downloaded in CI; synthetic tests verify software logic rather than NF-UNSW-NB15-v3 performance.

## Standalone & Clean VM E2E verification

Public Windows binary distribution (`Issue #73`) requires `verify_companion_artifacts.py --verify-e2e --standalone-embedded` on the build host plus `scripts/vm_target_e2e.ps1` on a Clean Windows 10/11 VM. Any `SKIPPED` dataset step, even with exit code 0, must remain labeled `SKIPPED` in all reports.

See the [testing guide](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/TESTING.md), [CI workflow](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/.github/workflows/ci.yml) and [v1.0.0 release notes](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/releases/v1.0.0.md).
