## Standalone packaging architecture (v1.0.0)

In **NetFlow Sentinel v1.0.0**, the Tauri 2 + Svelte 5 process launches a **PyInstaller FastAPI Sidecar** (`scripts/build_backend_sidecar.py`, `desktop/src-tauri/tauri.standalone.conf.json`) on `127.0.0.1` with a 256-bit session token and local SQLite persistence.

When built on a developer/CI host with verified artifacts present:

- The Windows x64 NSIS installer embeds the sidecar, all four `.joblib` models, `nf_unsw_nb15_v3_preprocessor.joblib`, and 200-row `demo_flows.csv`.
- **End users** do not install Python, create a `.venv`, download an external Companion Bundle ZIP, or run `git clone`. App data is stored under `%LOCALAPPDATA%\NetFlowSentinel\`.
- **Developers** can still build/run in `DEVELOPMENT` mode from the `v1.0.0` Source Release.
