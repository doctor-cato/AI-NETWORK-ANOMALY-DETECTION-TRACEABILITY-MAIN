## Packaging architecture (v0.6.0)

The Windows x64 NSIS installer (`NetFlow-Sentinel-v0.6.0-windows-x64-setup.exe`) bundles the **Svelte 5** frontend, **Rust / Tauri 2** host, **Python backend source** (`src/network_anomaly/`, `scripts/run_api.py`, `requirements-runtime.txt`) and tracked **SHA-256 manifests** (`reports/`). Users do not need `git clone` or `NETWORK_ANOMALY_REPO_ROOT`. User state (`.venv`, model `.joblib` files, `data/demo/`, `network_anomaly.db`) lives under `%LOCALAPPDATA%\NetFlowSentinelM6` for standard-user compatibility.

Because `NF-UNSW-NB15-v3` carries non-commercial reuse terms and `.joblib` binaries stay outside Git, target Windows machines require:

- **Windows 10/11 (x64)** with **Microsoft Edge WebView2 Runtime**.
- **Python `>= 3.12` (x64)** for `requirements-runtime.txt` compatibility.
- **Companion Bundle ZIP** (4 models + preprocessor + 200-row Validation demo CSVs), verified fail-closed via `COMPANION_SHA256SUMS.txt` and tracked manifests.
