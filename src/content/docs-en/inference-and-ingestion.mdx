## Three operational modes & `LiveStreamOrchestrator`

NetFlow Sentinel v2.0 unifies batch and streaming execution through `InferencePipeline` and [src/network_anomaly/streaming/live_orchestrator.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/src/network_anomaly/streaming/live_orchestrator.py):

1. **Mode 1 — Offline CSV Analysis**: Validates CSV files against `canonical-flow-v2-18`, rejects missing base columns as `FEATURE_INCOMPATIBLE`, verifies SHA-256 digests on `TrainOnlyPreprocessor`, `OODRejectionGate` and model `.joblib` files, and outputs traceable predictions.
2. **Mode 2 — Dataset Replay**: Streams canonical datasets through `LiveStreamOrchestrator` at **`399.44 flow/s`** median replay throughput (`process_batch(32)` achieves **`386.37 flow/s`**, `2.59 ms` mean batch latency in [reports/benchmarks/system_performance_benchmark.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/reports/benchmarks/system_performance_benchmark.json)).
3. **Mode 3 — Live Lab Monitoring (UDP NetFlow v9 / IPFIX)**: Decodes live UDP telemetry using the pure-Rust [telemetry/netflow-rs/src/lib.rs](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/telemetry/netflow-rs/src/lib.rs) collector ([docs/NETFLOW_COLLECTOR.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/NETFLOW_COLLECTOR.md)) or Python UDP listener, enforcing bounded template caches (`MAX_TEMPLATES_PER_SOURCE = 256`, `MAX_FIELDS_PER_TEMPLATE = 128`).

## Fail-closed `"deployment"` OOD gate & `OOD_AWARE_ENSEMBLE`

In default `runtime_mode="deployment"`, the pipeline refuses to initialize without a valid **`NETFLOW_OOD_GATE_SHA256`** matching the serialized `OODRejectionGate`:

- **`OODValidator` & `OODRejectionGate`**: Combines physical network-invariant checks with statistical feature-bound and Mahalanobis/quantile distance checks fitted on `AIT-NDS-v2` Train.
- **`ABSTAINED_OOD` semantics**: Flows exceeding the OOD threshold are immediately tagged **`ABSTAINED_OOD`** (`predicted_label = null`, `risk_level = "ABSTAINED_OOD"`) rather than forcing an unreliable closed-set prediction.
- **`OOD_AWARE_ENSEMBLE`**: Combines supervised probability estimates (`Random Forest`, `XGBoost`) with unsupervised anomaly scores (`Isolation Forest`, `Autoencoder`) and 16-D behavioral session features while preserving explicit OOD abstention.

See [docs/MULTI_SOURCE_INGESTION.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/MULTI_SOURCE_INGESTION.md) and [docs/FEATURE_COMPATIBILITY_MATRIX.md](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/36f63081bf30de98b1dc1058a780ae79ae2cf5b3/docs/FEATURE_COMPATIBILITY_MATRIX.md).
