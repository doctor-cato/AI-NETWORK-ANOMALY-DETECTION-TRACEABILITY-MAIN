## Benchmark validity & cross-dataset collapse

The verified package contains flows observed in early 2015 in an IXIA PerfectStorm testbed. `49.98%` of Validation rows and `53.21%` of Test rows share identical 47-feature vectors with Train, and a single `MIN_TTL` tree reaches `0.999849` Validation accuracy. On a 100,000-row external sample of `NF-CSE-CIC-IDS2018-v3`, `99.99%` of rows exhibit TTL shortcut drift and canonical Random Forest collapses to **`0.0000` Recall** and **`0.3802` FPR**. Meanwhile, under `Val FPR <= 0.05` and unscaled features (`scaler_type="none"`), the `MLPRegressor` Autoencoder achieves `0.1361` Held-out Test F1 and `0.1093` Recall.

## Packaging & distribution boundaries (v1.0.0)

This static research portal does not execute models. On `main` (`PR #72`), `v1.0.0` replaced external Python + Companion Bundle prerequisites with a build-time embedded **PyInstaller Sidecar**. However, public Windows `.exe` distribution remains **BLOCKED / DEFERRED** under [Issue #73](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/issues/73) and `DISTRIBUTION_AUTHORIZATION.json` (awaiting Clean Windows VM E2E & UQ `454104` license review); GitHub Release `v1.0.0` is currently a **Source Release**.

## Deferred operational capabilities

Live packet capture (PCAP), authentication/API log correlation, live OS firewall automation and production AES-256-GCM OS keyring key rotation remain **DEFERRED**. Security response simulation (#27) runs strictly in deterministic dry-run mode (`executed = false`). See [v1.0.0 release notes](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/releases/v1.0.0.md).
