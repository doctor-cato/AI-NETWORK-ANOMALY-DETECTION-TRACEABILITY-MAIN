## Repository structure (v2.0)

- **`src/network_anomaly/`**: Core v2 Python package (`data/v2_schema.py`, `data/taxonomy.py`, `preprocessing/pipeline.py`, `models/registry.py`, `behavioral/vector.py`, `crypto/aead.py`, `crypto/key_manager.py`, `crypto/rotation.py`, `streaming/live_orchestrator.py`, `api/response_policy.py`).
- **`desktop/`**: Svelte 5 + TypeScript frontend (`desktop/src/`) and Rust Tauri 2 host (`desktop/src-tauri/`, version `2.0.0`).
- **`telemetry/netflow-rs/`**: Pure-Rust NetFlow v9 (RFC 3954) & IPFIX (RFC 7011) packet decoder and UDP collector ([telemetry/netflow-rs/src/lib.rs](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/telemetry/netflow-rs/src/lib.rs)).
- **`data/` & `reports/`**: Tracked SHA-256 dataset/split manifests (`data/V2_SPLIT_MANIFEST.json`, `data/AIT_DATASETS_MANIFEST.json`, `data/EXTERNAL_DATASETS_PROVENANCE.json`), OpenAPI contract (`reports/api/openapi.json`), experiment reports (`reports/experiments/`) and governance audits (`reports/audits/`).
- **`historical/`**: Archived v1 (`NF-UNSW-NB15-v3`) records isolated from v2 runtime execution.

## Developer verification workflow

Run the full local verification gate from the repository root in PowerShell:

```powershell
python scripts/check_environment.py
python scripts/export_openapi_spec.py --check
python scripts/check_desktop_version.py --check
python scripts/verify_companion_artifacts.py --verify-distribution-permission research-only --target-channel local_offline
python -m ruff check src scripts tests
python -m black --check src scripts tests
python -m pytest tests -q -rs --tb=short
npm --prefix desktop run check
npm --prefix desktop run test
npm --prefix desktop run build
cargo test --manifest-path telemetry/netflow-rs/Cargo.toml --lib
git diff --check
```
