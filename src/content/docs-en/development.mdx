## Repository boundaries

On `main`, `src/network_anomaly/` holds research, ingestion, inference and FastAPI code; `desktop/` holds the **Rust / Tauri 2 + Svelte 5 (`v1.0.0`)** desktop app; `scripts/` holds CLI entry points and `build_backend_sidecar.py`; `data/` holds manifests and ignored CSV paths; `reports/` stores quality, evaluation, OpenAPI and governance manifests; `artifacts/` stores local `.joblib` binaries outside Git. This portal lives on the dedicated `site-source` branch.

## Basic checks

```powershell
python scripts/check_environment.py
python -m pytest tests/unit/test_basic.py tests/integration/test_pipeline.py -q
python scripts/check_desktop_version.py --check
python -m ruff check src scripts tests
python -m black --check src scripts tests
git diff --check
```

These checks do not replace real-data benchmarks. CI runs pytest against synthetic fixtures; dataset-dependent checks report `SKIPPED` when raw bytes or `.joblib` files are absent. See [testing guidance](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/TESTING.md) and [release process](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/docs/RELEASE_PROCESS.md).
