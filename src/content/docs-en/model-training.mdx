## Four frozen `E0` baselines on `ait_test` (`988,805` flows)

All four `E0` baseline models are trained strictly on `AIT-NDS-v2` Train (`2,097,891` rows; benign-only `2,051,908` rows for `IF` and `AE`), calibrated on Validation (`377,704` rows) and evaluated once on Held-out Test (`988,805` rows) in [reports/experiments/ml/model_comparison_report.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/ml/model_comparison_report.json):

- **Random Forest (`E0`)**: Held-out Test **`F1 = 0.9950`**, `PR-AUC = 0.9955`, `Recall = 0.9904`, `FPR = 0.000002` (`2` FP on `981,392` Benign flows).
- **XGBoost (`E0`)**: Held-out Test **`F1 = 0.9013`**, `PR-AUC = 0.9955`, `Recall = 0.9906`, `FPR = 0.001552` (`1,523` FP).
- **Autoencoder (`E0`, benign-only Train)**: Held-out Test **`F1 = 0.5877`**, `PR-AUC = 0.8007`, `Recall = 0.9854`, `FPR = 0.010323`.
- **Isolation Forest (`E0`, benign-only Train)**: Held-out Test **`F1 = 0.5842`**, `PR-AUC = 0.6780`, `Recall = 0.9902`, `FPR = 0.010538`.

## `ModelRegistry` 4 gates (`4/4 RESEARCH_ONLY`) & cross-source zero-shot drop

[src/network_anomaly/models/registry.py](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/src/network_anomaly/models/registry.py) enforces four promotion gates: (1) SHA-256 artifact integrity, (2) scenario-disjoint `ait_test` validation, (3) OOD gate pairing, and (4) zero-shot cross-source generalization (`cross_source_validated`). Because zero-shot transfer to `CTU-SME-11` (`251,219` rows) exhibits severe domain shift (`RF F1 = 0.4534`, `XGB F1 = 0.3405`, `IF F1 = 0.4090`, `AE F1 = 0.3125` in [ctu_cross_source_eval.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/ml/ctu_cross_source_eval.json)) and `UWF-ZeekData24` (`95,871` rows) is audited in [uwf_zeekdata24_cross_source_eval.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/ml/uwf_zeekdata24_cross_source_eval.json), all **`4/4` `E0` models are locked at tier `RESEARCH_ONLY`** (`cross_source_validated = false`).

## `E1` multi-domain adaptation & Stage-2 6-class taxonomy

- **`E1` Multi-Domain Experiment**: Adding target-domain representation in [e1_multidomain_experiment_report.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/ml/e1_multidomain_experiment_report.json) lifts `CTU_Test` performance to **`F1 = 0.9564`** (`XGB_E1b_weighted`, `FPR = 0.0442`) and **`F1 = 0.9531`** (`RF_E1a_pooled`), while benign adaptation (`AE_E3b`) reduces Windows 7 Active Directory benign false-positive rate from **`72.14%` down to `13.79%`**.
- **Stage-2 6-Class Attack Classification**: In [multiclass_attack_classification_report.json](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/18db24e637399d077312e60e4911e569b9b099d2/reports/experiments/ml/multiclass_attack_classification_report.json), `RF_multiclass` achieves **`Macro-F1 = 0.7347`** (`Weighted-F1 = 0.9960`) across the 6 canonical classes, with single-flow `Credential_Attack` (`Recall = 0.1410`) mitigated via Stage-3 16-D behavioral session correlation (`RQ3` session F1 lift to `0.9412`).
