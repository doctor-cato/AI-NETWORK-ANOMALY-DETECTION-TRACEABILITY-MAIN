## Input & preprocessing boundary

The canonical baseline uses 47 ordered NetFlow features (`nf-unsw-nb15-v3-baseline-47`), excluding `Label`, `Attack` and six trace metadata columns from matrix `X`. `TrainOnlyPreprocessor` fits strictly on Train (`1,655,797` rows): **no One-Hot Encoding** (`DNS_QUERY_ID` has `63,003` categories) and **no scaling** (`scaler_type = "none"`), applying median imputation (37 quantitative columns) and mode imputation + `np.round` `passthrough` (10 categorical-coded columns).

## Reproduction boundary

Large `.joblib` binaries remain outside Git (they are embedded into the PyInstaller sidecar only when building standalone bundles with local artifacts present). In development checkouts lacking local `.joblib` files, `InferencePipeline` and `/api/v1/models` enforce fail-closed SHA-256 verification and report `BLOCKED / NOT READY` (`HTTP 503`). Also note `xgb-baseline-1794755807` trained with `git_dirty=True` at `7f51390`, and historical RF vs canonical split index parity stays `MEMBERSHIP_EQUIVALENCE: NOT_VERIFIED` in the [split membership audit](https://github.com/doctor-cato/AI-NETWORK-ANOMALY-DETECTION-TRACEABILITY-MAIN/blob/e5a1f896effc1981792d0e9c44232ae29cf4ffd4/reports/splits/split_membership_audit_report.md).
