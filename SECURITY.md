# Security Policy

## Supported versions

Only the current development branch (`main`) is actively maintained for this course project.

## Reporting vulnerabilities

If you find a security issue (e.g., accidental secret exposure, unsafe data handling), report privately to project maintainers rather than opening a public issue.

## Data handling

- No network traffic data with identifying info is committed.
- UNSW-NB15 is not included; users download themselves and are responsible for access control.
- No API keys, tokens, or passwords in repository.
