# NetFlow Sentinel v1.0.0 — Source Release Notes

> [!IMPORTANT]
> **Đây là bản phát hành mã nguồn (`v1.0.0 Source Release`).**
> Bộ cài Windows x64 (`NetFlow-Sentinel-v1.0.0-windows-x64-setup.exe`), các tệp mô hình `.joblib`, `preprocessor.joblib` và dữ liệu `demo_*.csv` **không** được build, upload hay đính kèm trong GitHub Release công khai này. Bộ cài Windows chưa được nghiệm thu đầy đủ trên Windows 10/11 x64 sạch và quyền phân phối công khai cho mô hình/dữ liệu dẫn xuất từ **NF-UNSW-NB15-v3** (`UQ License ID 454104`) vẫn đang **`BLOCKED`** tại [`DISTRIBUTION_AUTHORIZATION.json`](../../reports/governance/DISTRIBUTION_AUTHORIZATION.json).

Phiên bản **NetFlow Sentinel `v1.0.0` Source Release** đóng gói đầy đủ mã nguồn Desktop **Rust / Tauri 2 + Svelte 5**, **Python FastAPI + 4-model ML backend**, **PyInstaller sidecar packaging toolchain**, tài liệu hướng dẫn và bộ kiểm soát provenance/governance để phục vụ nghiên cứu, audit và tự build cục bộ (không sử dụng Companion Bundle cho kiến trúc v1.0.0).

---

## 1. Điểm mới nổi bật trong `v1.0.0`

- **Fully Embedded Windows Installer (NSIS x64):**
  - Đóng gói sẵn ứng dụng Desktop **Rust / Tauri 2 + Svelte 5**, **PyInstaller sidecar backend** (`netflow-sentinel-backend.exe` gồm FastAPI + Uvicorn + scikit-learn + XGBoost + SQLite persistence), **WebView2 Offline Installer**, **4 verified ML models**, **NF-UNSW-NB15-v3 preprocessor**, **feature/threshold/split manifests**, **demo CSV (`demo_flows.csv`, `demo_labels.csv`, `demo_manifest.json`)** và thông báo bản quyền (`NOTICE`, `THIRD_PARTY_NOTICES.md`, `LICENSE`).
- **Tauri Sidecar Lifecycle Management:**
  - Tự động khởi chạy `netflow-sentinel-backend.exe` khi mở ứng dụng, xác thực localhost qua `X-Sentinel-Session-Token` (CSPRNG per-launch), kiểm tra `/health` fail-closed, hỗ trợ tự khởi động lại sidecar và dọn tiến trình sạch sẽ khi đóng ứng dụng.
  - Dữ liệu chạy cục bộ (SQLite database, logs tạm) được cô lập tại `%LOCALAPPDATA%\NetFlowSentinel\`.
- **Cải thiện giao diện Svelte 5 cho người dùng cuối:**
  - Thêm hướng dẫn sử dụng **4 bước** (Nhập dữ liệu CSV → Phân tích → Đánh giá & Đối chiếu → Xuất báo cáo).
  - Dashboard trạng thái 4 mô hình, giải thích dễ hiểu **Benign / Attack / OOD (`ABSTAINED_OOD`)** và mức độ tin cậy (**Confidence**).
  - Phân biệt rõ nhãn kiểm chứng khoa học: **`Đã kiểm chứng khoa học (MODEL_VALIDATED)`** so với **`Thử nghiệm / Nghiên cứu (RESEARCH_ONLY)`**.
  - Chuẩn hóa thông báo lỗi tiếng Việt thân thiện khi gặp lỗi schema CSV, timeout hoặc sidecar chưa sẵn sàng.
- **Release Pipeline, Governance & Embedded Verification Gate:**
  - Chuyển sang cơ chế **build-time artifact acquisition** (`MODEL_BUNDLE_URL` / `MODEL_ARTIFACT_RUN_ID` / `MODEL_BUNDLE_SHA256`, giữ tương thích fallback có cảnh báo deprecated cho `COMPANION_BUNDLE_*` mà không xóa secrets hiện có), chặn Rust target cache và luôn dọn workspace sau build.
  - Upload và publish chịu gate quyền phân phối ([`DISTRIBUTION_AUTHORIZATION.json`](../../reports/governance/DISTRIBUTION_AUTHORIZATION.json), `DISTRIBUTION_EVIDENCE_SHA256`, `NOTICE` và `THIRD_PARTY_NOTICES.md`). Khi publish, workflow dùng đúng bộ cài ứng viên đã nghiệm thu và xác minh báo cáo Windows VM với `--require-stable-windows-e2e`.

## 2. Trạng thái 4 mô hình đóng gói sẵn & Phạm vi khoa học

| Mô hình | Trạng thái trong `v1.0.0` | Nhãn quản trị khoa học | Chứng cứ trên `NF-UNSW-NB15-v3` Held-out Test (`345.953` flow) |
|---|---|---|---|
| **Random Forest** | `READY` (Embedded) | `MODEL_VALIDATED` | PR-AUC `0.9854`, ROC-AUC `0.9963`, Precision `0.9949`, Recall `0.8199`, F1 `0.8990`, FPR `0.0007` (`rf-heldout-ea330b9`) |
| **XGBoost** | `READY` (Embedded) | `RESEARCH_ONLY` | PR-AUC `0.9885`, ROC-AUC `0.9966`, Precision `0.9950`, Recall `0.8199`, F1 `0.8990`, FPR `0.0006` (`xgb-baseline-1794755807`) |
| **Isolation Forest** | `READY` (Embedded) | `RESEARCH_ONLY` | Unsupervised anomaly detection; PR-AUC `0.2145`, ROC-AUC `0.5831`, F1 `0.0258`, FPR `0.0566` (`if-c4-20261115T055359Z`) |
| **Autoencoder (MLP)** | `READY` (Embedded) | `RESEARCH_ONLY` | Reconstruction error (`Val FPR <= 0.05`); PR-AUC `0.2194`, ROC-AUC `0.6295`, Recall `0.1941`, F1 `0.2367`, FPR `0.0507` (`ae-heldout-real-20261116T040455Z`) |

> [!WARNING]
> **Giới hạn khoa học & OOD:**
> - **Random Forest (`MODEL_VALIDATED`)** là baseline chính đã qua đánh giá Held-out Test đầy đủ. Ba mô hình còn lại (**XGBoost**, **Isolation Forest**, **Autoencoder**) được nhúng sẵn để so sánh đa mô hình dưới nhãn **`RESEARCH_ONLY`** (không thay thế baseline kiểm chứng trong quyết định vận hành).
> - Dữ liệu ngoài phân phối `NF-UNSW-NB15-v3` (OOD — giá trị vượt ngưỡng phân vị `0.1%–99.9%` của tập Train hoặc feature contract mismatch) được đánh dấu **`ABSTAINED_OOD`** thay vì ép dự đoán sai.
> - **Issue #27 (Adaptive Rotation & Security Response):** Chế độ **Dry-Run (`OBSERVATION_ONLY` / `DRY_RUN`)** chỉ tạo khuyến nghị hành động (`NO_ACTION`, `MONITOR`, `INVESTIGATE`, `ISOLATE_RECOMMENDED`) trên dữ liệu demo/CSV; chế độ tự động thực thi tường lửa thật (**Live Enforcement**) vẫn **`DEFERRED`**.
