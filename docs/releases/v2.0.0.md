## 1. Kiến trúc & Điểm mới v2.0.0

- **Schema & Pipeline v2 (`canonical-flow-v2-18`):** Loại bỏ phụ thuộc `NF-UNSW-NB15-v3`; tiền xử lý `asinh_robust` khớp chỉ trên `AIT-Train`, kiểm soát OOD qua `OODReferenceGate` (`artifacts/ml/ood_reference_gate.json`).
- **4 Mô hình AI v2 (`AI Ready 4/4`):** `Random Forest`, `XGBoost`, `Isolation Forest` và `Autoencoder` (`MLPRegressor`) gắn SHA-256 chain với `data/V2_SPLIT_MANIFEST.json` và `reports/preprocessing/v2_flow_preprocessing_manifest.json`.
- **Multi-Source Telemetry, Behavioral Engine, Encrypted Vault & Adaptive Key Rotation:** Tích hợp chuẩn hóa đa nguồn (`Flow`, `Identity/Auth`, `DNS`, `App/Web`), tương quan phiên & truy vết đa chặng, và lưu trữ mã hóa AEAD + bảo vệ khóa qua DPAPI.
- **Standalone Windows Desktop (Tauri 2 + Svelte 5):** Nhúng sẵn WebView2 Offline Installer và PyInstaller backend sidecar; không cần Companion Bundle rời.
